Flight Delays: Does Day of Week Predict a Late Departure at ATL?
==================================================================

This project explores whether the day of the week is associated with the
likelihood of a delayed flight departure out of Hartsfield-Jackson Atlanta
International Airport (ATL), the world's busiest airport, and compares that
pattern to nationwide TSA passenger volume.

Note on origin: the notebook started from a guided data-analysis exercise
template (structured as "Activity Goals" prompts). The core walkthrough
(cells computing delays and the day-of-week bar chart) follows that
template; the passenger-volume comparison, the limitations section, and the
code-quality fixes described below are original additions.

Data Sources
------------
Flight data was extracted using the `anyflights` R package
(https://github.com/simonpcouch/anyflights), similar in spirit to
`nycflights13` (https://github.com/tidyverse/nycflights13). We selected
ATL and year 2023, which contains 336,434 total flights; the CSV here is a
random sample of 5,000 of those flights.

Passenger data comes from the Transportation Security Administration (TSA),
which publishes the daily number of people passing through TSA checkpoints:
https://www.tsa.gov/travel/passenger-volumes/2023

Key Findings
------------
- Tuesday has both the lowest average TSA passenger volume nationwide and
  the lowest percentage of delayed ATL departures (~15.4%).
- Friday and Sunday have both relatively high passenger volume and the
  highest delay rates (~22.6% and ~23.4%).
- The pattern is suggestive of a link between overall air-travel demand and
  delay frequency, but it is a nationwide-vs-single-airport comparison, so
  it should be read as correlational, not causal. See the notebook's
  Limitations section for details.

Limitations
-----------
- The flight sample is 5,000 of 336,434 ATL departures (~1.5%); day-of-week
  percentages are estimates, not exact population values.
- Results are specific to ATL and to 2023, and may not generalize to other
  airports or years.
- The passenger dataset is nationwide, not ATL-specific, so the comparison
  to ATL delay rates is correlational at best.

Reproducing
-----------
Open flights-delays-project.ipynb and run all cells top to bottom. Required
packages: pandas, matplotlib. All file paths in the notebook are relative,
so keep the CSV/TSV files in the same directory as the notebook.
